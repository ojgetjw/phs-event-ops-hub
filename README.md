# PHS Event Operations Hub

Unified event planning, security coverage, and staff assignment system for Pembroke Hill School.

**Status:** Building (3-4 days to completion)

## Architecture

- **Frontend:** React + Vercel
- **Backend:** Supabase (PostgreSQL + Auth + Real-time)
- **Data Sources:** Arbiter Live (athletics), Google Calendar, manual submissions
- **Deployment:** Vercel + Supabase (production-ready)

## Key Features

- Central event dashboard (all events, all sources)
- Role-based access (KCPD Scheduler, Security Lead, Admin)
- Staffing assignment workflow
- Real-time updates
- KPI metrics
- Event workflow tracking
